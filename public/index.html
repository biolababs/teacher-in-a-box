First-time setup & deployment

Install the packages in training/requirements.txt into a local Python environment. Set TEACHER_PYTHON before starting this app.

The trainer saves a LoRA adapter. Use training/merge.py to merge it locally, then convert to GGUF using llama.cpp and import into Lemonade. See README for the complete workflow. No automatic model downloads occur.
